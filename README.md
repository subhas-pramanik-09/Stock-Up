# A Full Stack stock pricing a trading platform

Stock Up built using the MERN stack, offering stock trading, portfolio management and real-time market data. It provides a seamless trading experience with intuitive UI, charting tools, and order execution, ensuring a smooth and efficient platform for users to analyze, trade, and manage their investments.

## Installation

### Backend 
``` cd backend``` then ```npm start```
### Dashboard
``` cd backend``` then ```npm start```
### Frontend
``` cd backend``` then ```npm start```
